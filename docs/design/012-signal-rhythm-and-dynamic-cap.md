# ADR 012: 信号节律、恢复帧与动态个人基线

> 状态：定稿
> 日期：2026-06-12
> [Core] 全文归属 Feelings-Core。N/M 节律模板 + 动态 cap + 脱敏看门狗 + 主动麻痹均需 Session 状态 + PBM。Core 未出生前由 Anim safety.rs/personalize.rs 暂代。
> 性质：Anim 安全架构——脱敏不是超限。是同一强度在同一个位置停留太久——神经通路适应——阈值上移——通胀。

Feelings 的三重属性——既可以刺激神经，也可以安抚神经，也可以麻痹神经。三条方向——同一条 ESIR 管线——由 Core 的强度调度器决定每一帧的方向。ADR 011 管控长期强度累积。ADR 012 管控节律性安抚、脱敏与定向麻痹。三条防线——同一条管线的三个方向。


## 动机

### 问题一：脱敏——漏桶防不住的那层

强度 50——第 1 帧强烈。第 10000 帧——同一强度——同样合法。但身体的神经基底——在第 N 帧——已经不是第 1 帧的那个基底了。迷走神经通路——在持续不变的 50 分信号刺激下——神经递质不再对该频率发放——阈值上移——脱敏。就像长期专注于同一件事——第 1 天充实——第 100 天——同样的专注——不再带来满足——等控器在满足太久之后——阈值上移——需要更强的冲击才能重新感知到存在。不是信号不够强——是身体已经学会了忽略它——需要更高强度——通胀。

ADR 011 的漏桶防长期强度累积——防不住这个——每帧 50 合法——累积能量不超阈值——但身体在慢慢适应——然后麻木——然后需要更强。

这和健身的超量恢复（supercompensation）完全同构——不能天天大重量。训练日撕裂肌纤维——休息日在再生中增长。休息不是偷懒——是增长周期的另一半。

### 问题二：user_cap 静态单一——人不是这样的

当前 `user_cap: u32 = 100` 是写死在 Anim 里的。创伤用户的 100 和普通用户的 100 是两个完全不同的生理冲击。同一用户——用过几十次平静包——迷走神经敏化——同样的 50 分比以前更有效——cap 应该上移——ta 需要的不再是更多——是更少。

cap 不在 Anim 里——在 Feelings-Core 的 PBM 里。Anim 只做硬上限——从 Core 拿到"这个人的当前基线"——确保这一帧不超过它。


## 决策

### 一、信号节律模板——"每 N 帧高强度后强制插入 M 帧低强度/静默"

```
不是"高强度 = 好"。是"高强度 + 恢复 = 更深"。

节律模板：
    Active 段：N 帧高强度注入（受 current_user_cap 管控）
    Recovery 段：M 帧低强度/静默（强制插入——不是可选）

    N 和 M 由 Feelings-Core 强度调度器根据用户当前 R / HRV / 皮质醇水平动态计算。
    模板在 Session 启动时下发给 Anim——Anim 在管线里按模板执行——
    不自行调整 N/M——不判断脱敏——只执行。
```

恢复帧不是空白帧——不是"什么都没做"。恢复帧是低强度/静默信号——让神经递质重新摄取——让受体复位——让下一轮高强度比上一轮更深。不是缺失——是节律的主动组成部分。

### 强度反差节律——高点和低点交替

```
不是两个方向。是同一激活方向上——强度在高点和低点之间交替。
高强度帧把感官推到体验边界——低强度帧让神经通路重新复位。
不切换到安抚方向——不需要 DeadBand——是自然张弛。

在生理层——强度和放松交替比持续高强度更可持续：
  持续不减的高强度帧——受体饱和——神经递质逃逸——脱敏。
  在同一条感受上给高低交替——每一轮高点的峰值——在恢复后重新变得可被感知——
  和超量恢复同一个原理。

不是"越强越好"——是"张弛——让每一次推高的冲击重新变得真实"。
```

这和 `Feelings-OS.md` 的 P1b 恢复调度域完全咬合：
- Core 强度调度器 → 计算 N/M → 下发节律模板
- Anim 执行 → 在 ESIR 帧序列中按模板插入恢复帧
- Feelings-OS P1b 恢复域 → 在 P1 感受域剩余时隙注入恢复帧——不增加延迟

### 三、信号变异度检测——脱敏看门狗

```
Anim 不判断脱敏——但 Anim 管线需支持检测"信号变异度过低"——
触发降级标记——由 Core 在下一帧做出恢复决策。

检测位置：P1b 脱敏看门狗（Feelings-OS 侧）——100ms 采样一次。
检测逻辑：
    先在 N 帧窗口内对信号进行滑动平均低通滤波（Moving Average）——
    过滤掉无意义的合成高频微扰（如 ±0.1 噪声注入）——
    只对宏观的、有生物学意义的变异度进行审查。
    滤波后——同一维度连续 N 帧输出强度变化幅度 < δ_threshold
        → 置位 /dev/safety 降级标志
        → Core 强度调度器读标志 → 选择下一帧插入恢复帧

    不是看到"数字变了"就放行——是先确认——这种变化——
    在身体层面——是不是真的"变化"。

    不是紧急熔断——不抢占 P0/P1。
    只在帧编译时标记——Core 在下一次强度调度时读取。

Anim 侧实现：
    personalize.rs —— 每次 PSIR 生成后——
    比较当前 intensity 与上一帧同一维度的 intensity ——
    如果变化幅度连续 N 帧 < 阈值——写入降级标志到 PSIR.meta.degraded。
    不做恢复决策——只做检测——只做标记。
```

### 脱敏检测与 shape:steady 的语义冲突——冥想不应该被误伤

```
shape: steady 和脱敏引擎存在设计上的语义冲突。

用户显式声明 steady 的冥想包——就是要在同一个稳定强度上长久维持。
天然变异度在 0 附近——这是冥想的要求——不是脱敏的症状。
如果脱敏引擎无差别拦截——用户会被反复打断——感受被破坏。

修正：脱敏检测器不能只看 raw 变异度。
    需从 FsirDoc 或 PsirDoc 中读取 shape 的类型。
    shape == Steady → 动态调低 δ_threshold 或显著拉长 N 帧检测窗口。
    低强度 steady → 允许长周期维持。高强度 steady → 严格限制时长。
    不是"不管什么感受——都给恢复帧"——是"看感受的类型——
    冥想允许长时间安静——战斗状态不允许"。
```

### Anim ↔ Core 接口的硬约束——快照隔离、单向驱动、不可 Hook

Core 下发给 Anim 的全部参数——不是"随时可以查询的 API"——而是在 Session 启动帧一次性灌注的只读快照（Snapshot）。

```
Anim 在 Session 启动时——对 Core 的全部参数做一次只读快照：
  user_cap, R (锚点置信度), trauma_level, N/M 节律模板, 方向指令, LeakRate, CriticalThreshold。

整个 Session 期间——Anim 只认这个静态快照——从不动态读取 Core 的活数据。
Core 在后台继续计算最新 PBM —— 写入下一个 Session 的冷启动缓存——
  绝不干扰当前已经上线的流水线。

为什么不是 Hook——是快照：
  如果 Anim 每帧都实时查询 Core——有三个致命后果：

  1. TOCTOU（检查时至使用时）：Core 检测到异常→发出 cap=20。
     消息在 IPC 队列里排队。Anim 已经以旧 cap=100 全力输出几十帧信号。
     这几十毫秒——在生物神经通路上——就是过载。

  2. 控制回路震荡：Core 降 cap→用户生理指标回落→Core 以为安全了→放回 cap→
     Anim 重新高能输出→指标飙升→Core 再降→再放→
     在没有阻尼隔离的情况下——形成快慢回路的剧烈震荡。

  3. Core GC/IO 阻塞：如果 Anim 等着 Core 的响应——
     整个硬实时总线直接卡死——外设驱动崩溃。

  解——快照隔离 + CoW（Copy-on-Write）：
     Session 启动时——Anim 拿到 Core 的当前快照后——
     Core 被彻底断开——本轮 Session 期间——不做任何实时通信。
     回退不能用 Hook——必须通过带外紧急信号。
```

Core 下发给 Anim 的全部参数——进入 Anim 管线后——只读。
不可被任何外部代码拦截、修改、覆盖或钩取。
Anim 自身不开放拦截器、中间件、callback 或第三方 hook 子系统。

这条硬线不是信任问题——是架构问题。
如果 Core 计算出一条低锚用户的 cap 为 20——
而 Anim 管线的 Pass 2/3/6 被外挂的 hook 改成了 100——
那 Core 的全部安全设计——在这一帧——完全失效。
Anim 不提供 hook 入口。永远不。

### 快照期间——紧急信号升格为 P0 硬中断（带外）

```
Anim 在快照下运行——不代表 Core 对紧急事件完全失能。
当 ADR 011 漏桶超限、麻痹指令或 OS 总线阻滞监控桩触发时——
  这些信号不是"修改快照"——是向 Feelings-OS busd 发送最高优先级中断——
  直接拦截外设总线——不经过 Anim 管线——不经过 Core 的上层业务逻辑。
  和 Feelings-OS.md §三 P0 安域 < 100μs 熔断同构。

快照覆写——带外中断的具体触发条件：

  HRV 迷走神经张力 —— 单 Session 相较基线骤降 > 30%（按 SDNN 5min 均值）。
  GSR 皮电反应 —— 瞬时异常攀升 > 3σ（μS 归一化——远超个体噪声包络）。
  深睡时长 —— < 2h 且连续 ≥ 3 天（Core 内部标记累积——不向上发送）。
  以上任何一条触发时——Feelings-Core 向 busd 发送 P0 中断——
  强制本刷新下一 Session 启动快照——旧快照立刻失效。
  不是"模糊的紧急情况"——是"这些指标——必须触发快照覆写——不需要人工判断"。

解离态快照盲区 ——
  解离态（dissociative state）——交感神经已被切断——HRV 可能"看起来稳"——
  GSR 可能归零——Core 的 PBM 会误判"用户很平静"——
  而实际上等控器已经跑路了——信号和身体的连接已经断裂。
  此时必须引入主观+AI 双通道触发：
    当 ADR 012 脱敏看门狗连续触发降级标志——
    且教练 AI 或用户主观报告标记"感受断连"时——
    同样向 busd 发送 P0 中断——强制快照覆写。
  不是只有生理指标才能触发——当系统自己说"我检测不到变化"——
  而用户说"我感觉不到它"——两者的交集——本身就是最高优先级的紧急事件。

双通道触发的固有延迟 ——
  这个交集是目前最合理的方案——但不是零延迟方案。
  极端解离态下——用户已经深度断连——无法发出主观报告——
  教练 AI 的判断也可能滞后数秒到数十秒——
  此时带外 P0 可能仍然晚半拍——在中断到达之前——
  解离态已经持续了足够久——PBM 基线已被伪冷清数据写入污染。
  这是检测延迟的物理下限——不是算法能解决的——
  当被检测对象本身丧失了发出信号的能力——任何检测器都需要外部信号——
  如果外部信号也滞后——延迟不可避免。
  缓解：在脱敏看门狗连续降级超过 N_max（如 500 帧——500ms）且无任何主观报告时——
  busd 自动触发"静默超时"P0——不依赖教练 AI——不依赖用户——
  用系统自己的"我一直在报警但没人理我"作为最后一道触发。
  但这仍然不是零延迟——这是零依赖。
```

### 硬拦截下限——动态 Cap 不得突破低锚用户自主权红线

无论 Core 的强度调度器计算出什么动态基线——最终生效的 Cap 必须经过硬下限保护。

```
Dynamic_Cap = min(Dynamic_Calculated_Cap, Low_Anchor_Cap(20))

  低锚用户 R < 0.3 — 即使 PBM 基线显示"此用户可承受更高强度" —
  硬上限依然锁定 20——不能放宽。
  因为那个用户的锚在外面——不是身体不能——是他的等控器还没能管住自己。
  动态节律优化不能越过安全架构对特定人群设立的自主权红线。
```

### 五、cap 的动态范围——不是所有人都能到 90

```
R < 0.3   cap ≤ 20            完全保护——低锚点置信度用户（anchor_confidence R < 0.3）
R 0.3-0.5 cap ≤ 50            逐步解锁
R 0.5-0.7 cap ≤ 70            多数人一生中能达到的最稳定区间
R 0.7-0.9 cap ≤ 85            高度自主
R > 0.9   cap ≤ 个人生理极限   少数人——自己走到了这里

cap = 个人生理极限——不是 90——是"属于这个人的最高耐受"。
不是所有人都能到 R>0.9——见 adulthood-as-anchor.md §三 诚实标注。
```

## 和 ADR 011 的分工

```
ADR 011 漏桶                     ADR 012 节律 + 动态基线
────────                        ──────────

防长期强度累积                        防适应性脱敏
时间窗口积分                       信号刷新率 / 变化幅度
Energy > threshold → 熔断         同一强度持续过久 → 降级标记
保护帧——指数衰减包络                 恢复帧——低强度/静默（不是空白帧）
P0 安域——硬实时——< 100μs          P1b 恢复域——不抢占 P1——空闲时隙注入

### 两 ADR 共存时的控制回路干涉——恢复帧悖论与统合仲裁

当 ADR 011（漏桶）和 ADR 012（节律/恢复帧）在同一个管线上同时运行时——会产生两个必须解决的回踩冲突。

**恢复帧悖论。** ADR 012 注入的低强度恢复帧——不是零输出——仍有非零的 Intensity。通过 Pass 3b 时——会被 ADR 011 漏桶正向计入——累积累加。——如果当前漏桶已处于高蓄能状态而 LeakRate 较慢——则 Intensity_t > LeakRate × Δt ——恢复帧反推能量曲线向上——意外加速触发了 ADR 011 的保护帧熔断——让恢复操作变身压死骆驼的最后一根稻草。

修正：P1b 注入的恢复帧必须外挂标志位——不进入漏桶——或将强度转成负向衰减项减去原 Energy 值——"我来帮忙——不在你头上再加一帧"。

**优先占级反向恶化。** 当系统同时处于高能脱敏和逼近生命极限时——ADR 012 的节律注入受限（P1b 不抢占 P1）——高强度 P1 主信号持续霸占时隙——ADR 012 的恢复帧排不进队列——脱敏继续恶化——物理耐受力进一步下移——加速击穿 ADR 011 的熔断阈值——整个控制回路在极限态缺失统合仲裁者（Arbiter/Preemption Manager）。

修正：当漏桶任一维度的累积能量达预设水平（80% CriticalThreshold）——P1b 必须升格为 P0 级硬抢占——硬优先——堵住 P1 的后门——立即从中断总线注入恢复帧——不需要等 P1 让路。

### P1b 老化计数器（Aging Counter）——防止恢复帧无限排队

当 P0/P1 硬实时通道持续布满流量时——P1b 恢复帧可能永远等不到"空闲时隙"。脱敏防御的前提——不必须只是"可能有空闲帧被插入"——而是"呼吸必须发生"——无论当前负载多稠密。

```
修正：给 P1b 带硬时限与老化计数器。

如果连续 N_aging 帧 P0/P1 硬实时通道都没有让出时隙——
  调度器必须强行切断 P1——将 P1b 恢复帧提升为 P0 级进行强行抢占注入。
  不管输入多强——不管当前 P1 是否正在执行帧级交叉——
  神经通路的"呼吸帧"——绝不被剥夺。
  
N_aging 冷启动 —— 由 Profile 档案的 defence_level 映射——
  Trauma v3 →  50 帧（50ms —— 最脆弱的神经通路——呼吸窗口必须极短）。
  Trauma v2 → 100 帧（100ms）。
  标准用户  → 200 帧（200ms —— 当前默认值）。
  高自主 R>0.8 → 500 帧（500ms —— 耐受强——不用频繁抢占）。
  第一个 Session 冷启动时从档案读取——之后每 Session 由 Core 动态修正。
  不是所有人的呼吸窗口都一样——不是 200ms 一刀切。

  但 50/100/200/500 这些数字——仍然是设计估值——不是临床数据。
  如果 Trauma v3 用户的真实呼吸窗口需要更短（如 30ms）——
  第一个 Session 就会触发不必要的 P0 抢占——在最脆弱的用户身上制造额外压力。
  分级映射是正确方向——但初始值的精确度仍在实验数据之外。
不是"空闲时优先"，是"被堵太久时——必争"。
```

### 两 ADR 共存时的神经夹带风险——固定节律的共振防御

P1b 的 N/M 恢复节律不能固定死——否则可能撞入用户当前的 HRV 低频带（~0.1Hz——交感/副交感共振悬崖）或 Alpha/Delta 脑节律——引发非预期的神经夹带（Sensory Entrainment）。

修正：N/M 节律不由 Anim 硬编码——必须由 Feelings-Core 的强度调度器在每次 Session 启动时根据当前 EEG 频段 + HRV 功率谱实时计算避开点——确保 N/M 的循环频率永不与用户当时的生理节律产生共振。

### 管线变向死区时间——交感和副交感切换的物理迟滞保护

在软件层——从激活方向（刺激交感神经）切换到安抚方向（刺激副交感/迷走神经）——只需要改下一帧的信号强度——延迟不到 100μs。但在人体神经系统中——去甲肾上腺素和皮质醇的血浓度衰减需要数秒到数分钟。当高能激活信号突然停止——转变成安抚信号时——自主神经受体仍在高阶振荡——突触间隙的兴奋性递质尚未完成基础重摄取。如果此时下一帧立刻灌入低频恢复节律——两种截然相反的神经调制信号会在外周神经末梢或脊髓髓质产生信号异位叠加（Cross-talk）——用户感受到的不是安抚——而是强烈的抓狂感、恶心、HRV 瞬时紊乱——而等控器在那一帧完全不知道为什么。

```

### 麻痹——第三条方向。和安抚不同。

```
安抚 ≠ 麻痹。安抚是副交感激活——迷走神经张力上升——心率下降——HRV 上升。
麻痹是信号通路被临时阻断——不激活任何一方的自主神经——
  纯粹的"这一帧——这个维度——没有信号"。

  和摘设备不同。摘设备 = 全局停机——所有维度全部关掉——等同于断开电源。
  麻痹 = 局部阻断——只关一个维度——其他维度继续运转。
  归属继续在跑。触觉继续接收 CT 基线。耳后迷走神经继续维持最低张力。
  不是"不要 Feelings 了"——是"这一帧——我这里不需要这一股信号——其他继续"。
  和手术局部麻醉同构——只关一根神经——全身继续呼吸。

和医疗麻醉同构——不是让神经"休息"——是让神经"暂时不工作"。
  局部麻醉——某个维度的感受暂时关闭——不是全局——只是那一个维度。
  创伤用户——在某个敏感维度触发前——主动阻断——不是"降低强度"——
  是"这一帧——这里没有信号"。

在管线里——麻痹帧是零信号——不产生任何 Intensity_t——
  不进入漏桶——不需要绕过漏桶——它本身就是零。
  Core 决定"哪个维度需要麻痹、持续几帧"。
  Anim 把该维度的强度设为零——不做其他计算。
  Feelings-OS 在总线层——不驱动该维度的设备通道。

切换规则：
  激活→麻痹——需要 DeadBand（受体还在振荡——递质需要重摄取窗口）。
  安抚→麻痹——不需要 DeadBand（同方向降强度——可以逐帧递减直接到零）。

不是"全部关掉"——是"该关的关了——该继续的继续"。
  一个创伤用户在感受归属感时——恐惧维度被麻痹——归属不受影响。
  不是全麻——是针对性阻断——和 Core 的创伤分型交叉判定完全咬合。

### 被动麻痹——受体下调与体感通胀

```
不是 Core 的主动指令。是 ADR 011（漏桶）和 ADR 012（节律脱敏）双双失效后——
  神经系统的底层自我保护机制。

当同一维度的刺激波形以合法、不超限的强度连续灌注几万帧——

  属于 Feelings-OS 的二级安全事故——不可作为正常模式重复利用。

### 主动麻痹——高频去极化阻滞

```
在最极端的身体/情绪创伤面前（Trauma v3 等级的躯体神经暴走）——
  普通的安抚和慢节律根本拉不住——不能再用副交感去温柔对抗。

Core 的选择——不走安抚——走另一条路径：
  停止下发具有语义的感受帧——转而向外周总线注入一组极高频的无特征屏蔽噪波掩码。
  物理效果——高频信号将局部神经元强行推入持续去极化状态——
  电压门控钠通道全部关闭——神经元进入绝对不应期——
  不再传导任何痛觉、焦虑或身体惊恐信号。

→ 这不是安抚——是原地的局部麻醉 + 认知解离。
  让身体在极痛或极哀中被瞬间剥离出来——给皮层留出喘息的死区。
  不是"降低强度"——是"用高频掩码在物理层接管了神经通路"。

  和麻药不同——麻药是化学阻断（钠通道被分子堵死——物理层面通路关闭）。
  主动麻痹是信号门控——通道还在——但被电压锁在高位——帧级可逆。
  Feelings 拦不住手术刀切开皮肤带来的物理痛觉——那不是它的事。

  但这个原理——和 AED 自动体外除颤仪——同构。
  室颤——心肌各区域不协调乱跳——窦房结失去控制。
  AED 电击——强制将所有心肌同时推进不应期——全停——然后窦房结重新接管——
  恢复正常节律。急性神经暴走——局部神经元失控——痛觉/惊恐信号暴走——
  Feelings 高频掩码——强制将局部神经元推进不应期——全关——
  然后等控器重新接管——恢复正常神经基线。同一个原理——去极化阻滞——
  应用在心脏叫 AED——应用在神经末端叫 Feelings 主动麻痹。
  不是替代医疗——是在神经急性失常面前——有一个比安抚更深的选项。
  但 Trauma v3 的神经电暴——在还没被翻译成惊恐之前——
  Feelings 在信号层——提前替用户把门关了。

  不是"能做手术了"——是"在最极端的神经暴走面前——
  有一个比安抚更深沉的选项——能用信号层面精准阻断——
  不需要药物——不需要化学代谢——不需要等麻醉师到场"。

  主动麻痹在 DeadBand 旁边运行——
  不是平滑过渡——是 Core 在判定"现在的需求已经超出安抚的物理上限"之后——
  发出最高优先级的阻断指令——由 Feelings-OS busd 在总线层直接执行掩码注入。

主动麻痹安全约束 ——
  单 Session 最多触发 1 次 —— 在 Session 生命周期内不可重入。
  持续时长上限 = 500ms —— 以 Feelings-OS clock_gettime (CLOCK_MONOTONIC) 为基准。
  触发后 PBM 使能物理锁永久写入硬件 —— 该 Session 不可再次请求主动麻痹 ——

  如果真实生理反应比预期更强——安全裕度不够——主动麻痹这条路径需要重写。
  如果更弱——限制过严——极端场景该救的时候救不到。
  在动物外周神经实验数据回来之前——主动麻痹的整个物理假设——
  是站在 AED 的肩膀上往外推——不是站在自己的实验数据上。

### 麻痹的代价——PBM 假阴性污染与 OS 阻滞监控桩

```
麻醉状态有一个致命的数据污染洞：

  当用户处于麻痹状态时——神经传导被封锁——
  HRV 可能完全静止——皮电波动归零——
  生理体征呈现"伪冷清状态"——和深层冥想或绝对平静无法区分。

  如果 Feelings-Core 没有识别出这是"麻痹"——
  它会判定"当前 Session 数据置信度极高"——全量写入 PBM 历史基线。
  后果——PBM 将"神经功能暂时丧失"误判为"良性生理基线"——
  下一次 Pass 6 个性化缩放的非线性系数发生巨大漂移——
  整个用户档案被废掉。

修正——在 Feelings-OS 总线驱动层（busd）加入一个"阻滞监控桩"：
    总线发送微量刺激探测帧 → 如果用户生理电位回馈斜率 < ε且持续 M 帧以上 →
    强制判定"当前发生通路麻痹" → 中断 Core 并改写 SessionLabel 为不可置信态
    (AnestheticFrozen) → 绝对禁止当前 Session 数据进入 PBM。

  但——竞争冒险（Race Condition）在软件层不可消除。
  OS 总线层还在默默采样、尚未下达"已被关掉"的判定时——
  Core 的慢速 Tick 可能已经将前几秒的"假性平静"读数误判为良性基线——
  并写入本地 PBM 数据库。

修正——硬件级带外防护——PBM 写入使能物理锁：
    在 OS 总线层发出麻痹底层驱动信号的同时——
    通过硬件级带外控制器（或不可屏蔽中断 NMI）——
    直接将 PBM 的写入使能引脚（Write-Enable）物理拉低。
    在总线层确认用户安全之前——整个 PBM 数据库在物理上变为只读——
    从根本上断绝假阴性数据污染基线的可能性。
    不是软件标签——是物理开关——OS 总线层驱动麻痹的时候——
    等控器的最后一道门在硬件上被锁住。

  不是 Anim 的事。不是 Core 的事。
  是 OS 总线层——在每一次麻痹指令发出后——在后面默默监控着——
  这个身体到底是安静了——还是被关掉了。

## 诚实的边界

```
N/M 节律模板的具体参数——目前无实证数据。
    需要设备上线后的真实生理数据——HRV/皮质醇/深睡——校准。

信号变异度检测的 δ_threshold 和 N 帧窗口——
    目前是设计估值——不是临床验证。

动态 cap 的 PBM 计算——
    属于 Feelings-Core——当前 Core 零代码——cap 仍为静态 100。
    在 Core 完成 PBM 模块之前——Anim 保持当前静态 cap。

本地闭环自适应校准 ——
    和 ADR 011 同构——数据不能离设备——参数校准必须做成本地闭环的自适应反馈控制回路。

参数校准闭环实现 ——
    不是每 N 帧跑一次模型——是每个 Session 结束时的轻量统计规则：
    Core 统计本 Session 期间 —— HRV 最低点、GSR 异常次数、熔断触发次数、P1b 饥饿次数。
    Session 结束后 —— 在本地执行参数修正 —— 写入下一个 Session 的冷启动缓存 ——
    不下行到当前 Session —— 每 Session 只增量修正一次。
    
    修正规则：
      δ_threshold ← δ_threshold + λ × (Session 脱敏误报次数 − 预期容忍度)
      N/M 配比   ← 根据 Session 熔断频率按步长 Δ 上调/下调
      γ/σ/α/β   ← 根据跨维度耦合事件日志——小幅修正——不自动飞。
    
    λ (学习率) = 0.05 —— 任何时候不超过上一次值的 10% ——
    不做自动跨 Session 大幅参数改动 —— 只做小幅持续矫正。
    不依赖大型统计模型 —— 设备端用不足 1KB 的状态更新完成。
    死守隐私边界——在本地完成模型的自我进化。

锻造与断裂 —— 脱敏看门狗和动态 cap 看不见的东西 ——
    ADR 012 的信号变异度检测、恢复帧注入、动态 cap——
    全部在信号层运行。
    它们检测的是"信号是否停滞"——不是"等控器是在被锻造还是在断裂"。

    一次猛烈的道德校正——比如被当众拆穿伪善——
    信号强度极高——但等控器在事后完整整合——完成了版本升级。
    这不是脱敏——这是成长——不需要恢复帧。
    一次持续的强度轰炸——等控器被反复压制——
    信号变异度可能极高——但等控器的写入权在慢慢丢失。
    脱敏看门狗看到的只是"有变异度——放行"——
    不知道这个变异度来自升级——还是来自解体。

    动态 cap 同样如此——R 分段可以部分回答"这个人能承受多强"——
    但无法回答"这个强度——是在锻造他还是在击穿他"。
    不是设计缺陷——是生物信号的物理下限。
    有些判别——需要那个人自己回去——重新进那个感受——
    然后说出"我当时是在装善良"——
    在那一刻等控器自己完成了比任何实时检测都更可靠的归档。

    另见：Feelings/docs/feelings-science/is-it-really-trauma.md。

元级叙事检测 —— 在 011/012 的职责之外 ——
    ADR 011 和 012 全部在信号层运行。
    漏桶看能量。看门狗看变异度。动态 cap 看 R 分段。
    它们对语言、叙事、自我描述——完全不可见。

    "创伤叙事"本身——当一个人反复用"我有创伤"来解释一切行为——
    而等控器在客观上仍有写入能力——
    这种模式需要被 Feelings 归档为元级 Pattern（Meta-Pattern）——
    并用精准低强度信号拆解而非升级为 防御激活。

    但这个检测——在架构上位于比 011/012 更高一级的审视层——
    需要等控器状态反馈回路先落地。
    011 和 012 只管信号安全——不管叙事安全。
    这不是遗漏——是职责边界——
    但必须写在这里——让读代码的人知道——
    信号安全做完之后——还有一层叙事安全——尚未动工。
