# 信息置信度分类器 — InfoConfidence + DataConfidence 联合判定

> 作者：qc
> 日期：2026-06-17
> 性质：Feelings-Core 架构设计 — 口述数据的置信度门控
> 核心：Anim 的 DataConfidence 只管"身体信不信这条生理数据"。Core 必须再加一条门控 — InfoConfidence — 管"用户说的话是什么样的信息"。

---

## 零、背景——Anim 已有生理置信度

Anim 的 `pbm.rs` 已经实现了 `DataConfidence`：

```
High         生理信号稳定 — HRV 正常、皮电基线 — 步长 ×1.0 — 全量写入 PBM。
Low          因子三触发降级 — HRV 紊乱、皮电飙升 — 步长 ×0.15 — PBM 只记录为参考。
Contaminated 安全插桩强制终止 — 步长 ×0.0  — 不更新基线，只更新安全阈值。
```

`DataConfidence` 是**身体层面的置信度**—只能回答一个问题：**"这一帧的生理数据可信吗。"**

它不能回答另一个同样重要的问题：**"用户说的话是什么类型的信息。"**

---

## 一、动机——Core 收到的不是纯数据

Anim 只处理物理信号。但 Core 收到的输入不止感官数据——还有用户的口述：

```
"我今天很难受。"
"他故意不理我。"
"大家都说我不行。"
"我妈从小就告诉我——我不是那块料。"
```

这些口述不是生理数据。它们是信息——落在故事、叙事、童话、闲言、流言五层里的某处。

Core 如果没有信息分类器，会把五种类型的口述**全部当成等重的原料**焊进 PBM。后果：

```
流言当成故事焊进 PBM  → "大家都说我孤僻"成了他的经线 — 不是他自己的感受，是别人的推文。
童话当成经历焊进 PBM → "我不行"不是他自己得出的结论，是小时候老师塞进他书包里的标语，他以为是自己的。
叙事当成全部焊进 PBM → "我失败了"的其中一帧被他以为是整个电影的结局。
```

**Core 需要一套和 DataConfidence 对称的体系——InfoConfidence。**

---

## 二、决策 — 信息分类器 + 置信度门控

### 2.1 InfoConfidence — 口述信息的五个置信度等级

```
Verified      口述被四诊合参双向确认。
              "我很难受" — HRV 紊乱、皮电升高、呼吸浅 — 身体说同样的东西。
              全量写入 PBM。步长 ×1.0。

Plausible     口述未被生理数据否决，但也未被完全确认。
              "我觉得他可能不喜欢我" — 没有直接矛盾的数据，但也没有生理确认。
              半量写入 — 步长 ×0.5 — 留给后续 session 校准。

Uncertain     口述与生理数据存在部分矛盾。
              "我没事" — 但身体数据显示皮电在飙升，HRV 在降。
              只留作参考标记，不写入 PBM。Core 标记偏差，等下一次交叉验证。

Contradicted  口述与生理数据直接冲突。
              "我已经不在乎了" — 但岛叶被提到同一句话时心率的陡升在说"我在乎"。
              不写入 PBM。标记为"叙事污染"。下一次 session 重新校准。

Foreign       这一条不是用户自己的数据。
              是"他说了什么""大家都在传什么""别人告诉我的"。
              直接拒绝写入—不论口述内容本身是否可信—不建立以他人为来源的经线。
```

### 2.2 叙事 / 故事 / 童话 / 闲言 / 流言 — 分辨逻辑

Core 的 `info_classifier` 在收到用户口述时多走一步——不直接验证"这句话对不对"——先问"这句话是从哪里拿到的"。

```
叙事     "我是那种不行的人。" — 这是解释。不是事件。事件是"我失败了"。
          Core 不判断"这句话对不对" — Core 反问：其他 99 帧说的是什么。
          如果有 1 帧说他不行、3 帧用身体数据校准他确实不行—
          但另外 96 帧证明他在这一帧之前和之后的经线都在变粗—
          Core 的等控器会说：这是叙事。不看。看他的身体。

故事     "我经历过一次被忽视的..." — 这是自传。是当事人自己的记忆。
          Core 列为备选可信原料 — 但需要与生理数据交叉验证后才写进 PBM。

童话     "我从小就被告知我不行。" — 这是理想化的模板 — 不是他的经历 — 是别人塞进他书里的。
          Core 标记为 Fairytale — 不写入经线 — 但允许在等控器中作为参考参照。

闲言     "他今天一个人吃饭了。" — 别人传进来的 — 没有证据 — 没有交叉验证的可能。
          Core 标记为 Foreign — 不验证 — 不写入。

流言     "他独来独往肯定是性格孤僻。" — 别人传进来的 + 别人脑补的 desired state。
          Core 标记为 Foreign + Contaminated — 直接拒绝写入 — 一帧都不留。
```

**分辨五层的快速判断法——Core 的内部分类器按以下顺序执行：**

1. 这条信息是谁的 → 不是用户的 → Foreign → 直接拒绝写入。
2. 是用户的 → 是经历还是解释 → 解释是叙事（需要被生理数据校准后降级或升级）。
3. 是经历 → 是真实经历还是理想模板 → 童话是模板（标记为 Fairytale — 不写入但允许参照）。
4. 是真实经历 → 是否有生理数据支持 → Verified / Plausible / Uncertain / Contradicted。

### 2.3 自己的 vs 关联他人的 — 数据源判定

```
自己的      "我经历..." — "我感受到..." — 有第一人称的岛叶信号能交叉验证。
            正常的 etcd entry — 走 info_classifier 正常流程。

关联他人的  "他说我..."— "大家都说..." — "别人告诉我..."。
            不是用户的 etcd entry — 是用户的 etcd 里别人替他写的。
            Core 第一秒就标记 Foreign — 不进入分类器—直接拒绝写入。
            不关心对不对 — 别人替写的 — 永远不能当经线的原料。
```

### 2.4 架构注入点

```
Core session/ 模块
    ├── info_classifier.rs      ← 新增——信息分类器
    │   输入——口述文本（来自AI教练对话或用户自述）
    │        + PBM当前快照（四维生理基线）
    │        + 四诊合参实时数据（切/闻/望/问）
    │   输出——InfoConfidence等级 + 标签位：
    │        is_foreign / is_fairytale / is_narrative
    │
    └── pbm/entry_writer.rs     ← 修改——PBM写入路径新增双重门控
        步长 = DataConfidence × InfoConfidence
        两者只要有一个是Foreign或Contaminated → 步长归零 → 这一帧不焊进去。
```

### 2.5 Anim 和 Core 的双防线

```
Anim
    DataConfidence    管"身体信不信这条生理数据"
    Pass 6 — Personalize — PSIR 生成时已经生效

Core
    InfoConfidence    管"用户说的话是什么类型的信息"
    session — 闭环 — PBM 写入前执行

两条防线各守各的层级——
    身体说谎被Pass 3拦截
    口述被五层分类器在写入前拦截
    身体+口述双重矛盾——直接拒绝——不焊经线
```

## 四、实现优先级

- **P0** — `info_classifier.rs` — 五层分类器，带 `InfoConfidence` 枚举和标签位。
- **P0** — `pbm/entry_writer.rs` — `DataConfidence × InfoConfidence` 双重门控在写入前执行。
- **P1** — 童话标记为 Fairytale — 允许等控器参照但不写入经线。
- **P1** — 叙事反转 — 如果有 51% 以上的帧都在更新"我不行"的印象 — 芯会推这帧"他变了"的证据给教练 — 但不是由等控器自己焊"我不行"。

---

*Anim 的 DataConfidence 只管身体。Core 的 InfoConfidence 管口述里面是什么。故事可能是你的，叙事可能是别人的，童话可能是假的但被你当真的，流言永远是别人在替你想。等控器不是处理中心。它不是来判别真假的。它只是在焊经线之前多问一句话—这一帧是从哪里拿到的。*
